# Webseiten von Fischer Consulting Partner

Dieses Repository enthält ausschließlich das Aussehen der Webseiten: Seiten, Gestaltung, Bilder und Schriften als statische Dateien.

Es enthält keine Kundendaten, keine Zugangsdaten und keinen Programmcode für das Formular. Der Webserver prüft regelmäßig, ob sich hier etwas geändert hat, und übernimmt dann nur statische Dateien.

Der Inhalt wird aus einer Vorlage gebaut und nicht von Hand bearbeitet.
